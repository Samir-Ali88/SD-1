# SOLO — Personal Portfolio Website

A responsive personal portfolio website built with HTML5 and CSS3, developed to showcase academic background, technical skills, and personal projects.

## Overview

This project is a single-page personal portfolio for **Samir Ali (SOLO)**, a Computer Science & Engineering student at the International Islamic University Chittagong (IIUC). The site presents an introduction, a list of technical skills, featured projects with descriptions and source links, and a contact section with a working form layout.

## Features

- **Responsive Layout** — Built with Flexbox and CSS Grid, adapting smoothly across desktop and mobile viewports.
- **About Section** — A brief personal introduction with a profile image.
- **Skills Section** — A clean, tag-style display of core technical competencies.
- **Projects Section** — Card-based layout highlighting two projects, each with a description, technology stack, and a direct link to the GitHub repository.
- **Contact Section** — Includes a direct email link and a structured contact form (name, email, message).
- **Custom Dark Theme** — A cohesive dark color palette with monospace accents for a clean, developer-oriented aesthetic.

## Sections

1. **Header** — Site logo and navigation links (About, Skills, Projects, Contact).
2. **About** — Introduction covering academic background and current areas of self-study (competitive programming, Linux, Python, cybersecurity).
3. **Skills** — A grid of key technical skills including C++, OOP, Python, Linux, SQL, Networking, and Git/GitHub.
4. **Projects**
   - **GTK Chat System Using C/C++** — A client-server chat application using TCP sockets, multithreading, and a GTK graphical interface.
   - **Multi-Threaded Port Scanner** — A Python-based TCP port scanner using concurrent threads and socket programming for network reconnaissance.
5. **Contact** — Direct email contact and a message submission form.
6. **Footer** — Copyright notice.

## How to Run Locally

1. Clone or download the project files.
2. Ensure `index.html`, `style.css`, and the `images` folder are in the same directory.
3. Open `index.html` in any modern web browser.

No build tools, dependencies, or server setup are required — the site runs entirely as static HTML and CSS.
